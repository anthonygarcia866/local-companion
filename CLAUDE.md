# local-companion — rules for AI coding agents

- Read `CLAUDE.md` and `PROJECT_STATUS.md` at the start of every session.
- Update `PROJECT_STATUS.md` in the same PR as any behavior change, bugfix, or roadmap change.
- Windows shell: one command at a time, no `&&`; `curl.exe` not `curl`; npm only (no bun, pnpm or yarn).
- All gh commands target anthonygarcia866/local-companion. Never open PRs, issues, or comments on Louis-CFM/coucou.
- Never run `gh pr merge` without the owner's explicit approval in chat.
- Never commit secrets or keys; `.env` files are gitignored.
- Verification: a tool reporting success is not proof. After any build, confirm the output reflects the change (rebuild, check exe timestamp/size/hash, launch it). Prefer hands-on checks in real apps over passing unit tests alone.
- Privacy (this is the product): all outbound network access goes through a single choke-point module in Rust (created in Phase 0). The allowlist is **localhost + `api.anthropic.com`** (https on 443 only; owner, 2026-10-11, see `docs/vision.md` §3), in code since 1c (`net::ANTHROPIC_HOST`, merged 2026-10-13, PR #16). Text goes to the API only on the user's explicit request (a click, the rewrite hotkey, or holding a voice key: Ctrl+Alt+Shift+V to dictate, Ctrl+Alt+Shift+A to ask Glim, voice 1.5b and Decision A), after the card/SSN/IBAN scan, and request/response text is never logged. Phase 3 may add further gated exceptions only through that module, behind a per-task approval UI. No other code path may make network calls or spawn networked processes; the one child server, whisper.cpp's `whisper-server` for dictation (voice 1.5b), listens on 127.0.0.1 only, starts without proxy variables, and is reached through `net::request`. Voice actions may start the user's own apps on request (classic Outlook, the Codex and Claude apps, Claude Code in a repo after a click, and apps the user added in Settings → Writing → Apps Glim can open: only their names go to Claude, as `open_app`'s enum; the path stays local, is checked again in `voice::own_apps`/`platform::open_own_app` and is opened with no arguments and no shell) and drive classic Outlook through local COM to save a draft (1.5d) or, asked by voice within ~10 minutes, change the draft it just saved (its text then goes to the API with the change, after the scan; only its Outlook id is kept, in memory); Glim itself never sends an email and never makes a network call there. Any change adding a network call, telemetry-bearing dependency, or updater must be called out in the PR description. Enforcement must be verified empirically (attempt a blocked request, confirm it fails), not trusted from config.
- The choke point is `windows/src-tauri/src/net/mod.rs` (`net::request`, allowlist `net::ALLOWED_HOSTS`). Nothing else may use `reqwest` or open a socket — a test enforces it. Every webview window must be created with `BROWSER_ARGS` (`lib.rs`), which also switches off WebView2's own background traffic; check the whole process tree (`glim.exe` + its `msedgewebview2.exe` children), not just `glim.exe`, when verifying.
- Privacy: screenshots during testing are cropped to the app's own window before saving. Never save full-screen captures. Prefer `PrintWindow` on Glim's own window over cropping a screen capture: a crop found by colour can run into other windows. The island's window is mostly transparent: crop to the drawn panel, not the window rectangle, or other apps show through.
- Never send mouse clicks, scrolls, or keystrokes to the real desktop unless the owner has confirmed in chat that they're away from the keyboard. Before any UI automation, take one screenshot; if any window other than Glim is in front, stop and ask. Prefer non-invasive testing (unit tests, local fake servers, WebDriver/tauri-driver against the app) over driving the real mouse.
- Red mascot state (s-record) = screen recording only. s-delegate = data leaving the machine only (the Claude API calls from 1c on, and Phase 3 delegation). Never reuse them for other states.
- The mascot is ported from `docs/brand/glim-mascot.html`, never redrawn: change the design file and run `node scripts/port-lantern.mjs` (in `windows/`); don't edit `src/mascot/lantern.css` or `lantern-svg.ts` by hand.
- If a plan step turns out wrong, amend the plan doc with a warning note — don't silently fix code around it.
- The Coucou name, the Mochi character, and the sounds are © Louis Raillé, not MIT (see `LICENSE-ASSETS.md`, `NOTICE.md`) — never ship them. The app is Glim.
